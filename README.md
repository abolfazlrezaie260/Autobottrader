# Autobottrader (ربات اتوماسیون معاملاتی ایزیتریدر مفید)

این پروژه یک پیش‌نمونه (Prototype) برای اتوماسیون و ارسال خودکار سفارش‌های بورسی و عرضه‌های اولیه در سامانه **ایزیتریدر کارگزاری مفید** با استفاده از **Python** و کتابخانه **Playwright** است.

---

## ساختار و منطق عملکرد

1. **حفظ نشست کاربری (Persistent Context & CDP):**
   - کاربر اطلاعات ورود (نام کاربری، کلمه عبور و کد یکبار مصرف پیامکی 2FA) را مستقیماً در مرورگر وارد می‌کند.
   - وضعیت لاگین، کوکی‌ها و توکن‌ها در دایرکتوری `browser_profile/` ماندگار شده تا نیازی به هاردکد کردن اطلاعات کاربری در کد نباشد.
   - امکان اتصال به مرورگر در حال اجرا از طریق سوئیچ `--remote-debugging-port=9222`.

2. **المان‌ها و سلکتورهای سامانه:**
   - استفاده از سلکتورهای `data-cy` سامانه ایزیتریدر نظیر `[data-cy="order-buy-btn"]`، فیلد حجم `[data-cy="order-volume-input"]` و ساختارهای مبتنی بر Angular / AG Grid.

3. **رفتار ضد تشخیص (Anti-Bot Techniques):**
   - حذف فلگ `navigator.webdriver` و شبیه‌سازی ماژول‌های کروم رسمی.
   - شبیه‌سازی حرکات ماوس غیرخطی و کلیک تصادفی در مساحت دکمه.
   - تاخیرهای تصادفی میان تایپ و کلیک‌ها (Random Jitter).

4. **زمان‌بندی دقیق (Precision Scheduler):**
   - تنظیم زمان شروع ارسال با دقت میلی‌ثانیه‌ای (مانند `08:44:59.850`).
   - مکانیسم دو مرحله‌ای (Sleep منعطف + Busy wait لحظه آخر) جهت حداقل تاخیر در ارسال سفارش.

---

## فایل‌های پروژه

- `main.py`: نقطه ورود و چرخه حیات برنامه
- `trader.py`: ماژول اعتبارسنجی لاگین، مقداردهی فرم و شلیک سفارش
- `browser.py`: راه‌اندازی مرورگر و اعمال اسکریپت‌های Stealth
- `scheduler.py`: موتور زمان‌بندی دقیق
- `config.yaml`: تنظیمات نماد، حجم، قیمت و زمان
- `config.py`: بارگذاری و مدل‌سازی تنظیمات
- `requirements.txt`: نیازمندی‌های پکیج پایتون

---

## نحوه راه‌اندازی

```bash
# نصب پکیج‌ها
pip install -r requirements.txt
playwright install chromium

# اجرای برنامه
python main.py
```
